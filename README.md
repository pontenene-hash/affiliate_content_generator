# アフィリエイト記事・SNS・制作プロンプト生成アプリ

商品名または商品ページURLから、SEO記事、販売ページ（LP）、店舗販促、SNS投稿文、動画台本、画像・動画制作用プロンプトまで一括生成するStreamlitアプリです。販売目的は「アフィリエイト」「院内・店舗販売」「両方」から選べます。

商品ページが403などで直接取得できない場合は、Gemini URL Context、商品名検索の順に自動で切り替えます。ページ側の取得制限をAPIキーのエラーとして誤表示しないよう、取得エラーとGemini APIエラーを分けて案内します。

## 自動生成するもの

- 想定読者の深い悩み・検索意図
- 商品名からのWeb調査（GeminiのGoogle検索連携が利用できる場合）
- 公式情報を優先した商品情報の要約と未確認事項
- 主軸・悩み・比較・使い方別のSEOキーワード
- H2・H3のSEO見出し構成
- PREP法による完成記事（Markdown／WordPress HTML）
- 購入につなげる販売ページ（LP）原稿
- Instagramキャプションと9枚カルーセル構成
- X投稿文3パターン
- Facebook投稿文
- Threads投稿文
- LINE配信用文
- Googleビジネスプロフィール投稿文（店舗販売時）
- A4店内POP原稿（店舗販売時）
- Instagramリール台本
- YouTubeタイトル・概要欄・台本
- TikTok投稿文・台本
- 各SNS用の画像・動画制作用プロンプト
- ブログ本文の各H2・H3セクションに挿入できるイラスト制作プロンプト
- 商品紹介画像・A4店内POP画像の制作プロンプト

SNS投稿文には【PR】表記とアフィリエイトURLを自動挿入します。

## 制作プロンプトの対象

- X投稿画像（1200×675）
- Facebookアイキャッチ（1200×630）
- Threads投稿画像（1080×1080）
- LINE配信用画像（1200×900）
- Instagramカルーセル9枚（1080×1350）
- Instagramリール表紙（1080×1920）
- Instagramリール動画（1080×1920）
- YouTubeサムネイル（1280×720）
- YouTube横型動画（1920×1080）
- TikTok表紙・縦型動画（1080×1920）
- ブログ記事の各H2・H3用横長イラスト（1200×675）

プロンプトには、プロのイラストレーター品質、人物・表情・背景・光・配色・構図、求心力、媒体サイズ、禁止事項まで具体的に含めます。すべての画像・動画にはキャッチコピーを直接表示するよう指示します。

## 全素材へ適用する追加品質基準

すべての画像・動画プロンプトへ、20項目の共通品質基準を省略せず自動添付します。単なる説明用イラストではなく、InstagramやWeb広告で使える明るく清潔感のある販促デザインとして制作し、記事の文章をそのまま画像化せず、悩み・原因・解決策・商品やサービスのメリットを視覚的に再構成します。

- 単なる人物の立ち絵を避け、表情・視線・動作・姿勢・背景・小物・生活場面を記事内容に合わせる
- タイトルだけで終わらず、悩み・原因・対策・メリット・注意点など必要な短い説明を画像内へ配置する
- テキスト領域とイラスト領域を完全分離し、顔・身体・商品・重要部分へ文字を重ねない
- サブテキストはタイトルの約80％を基準にし、スマートフォンでも読める大きさを確保する
- 単語・熟語・正式名称・数字と単位を途中で分割せず、日本語の意味のまとまりで改行する
- カルーセル9枚の色調・書体・人物・タッチ・余白・装飾を統一し、内容に応じて構図を変える
- 1枚目は対象読者とテーマがひと目で分かる表紙、9枚目は【PR】を明示した優しい購入・確認CTAにする
- 動画は表紙→悩み→原因→解決策→商品・サービス紹介→CTAの流れを基本にする
- Reels・TikTokは上下左右の操作UI用安全余白を確保し、YouTubeは縦型の流用ではなく16:9専用に再設計する
- 商品名・店舗名・サービス名は元ページと記事の正式表記を一字一句守り、略称や英語名へ変更しない
- プロのグラフィックデザイナー、プロのイラストレーター、SNSマーケティング担当者の3視点で確認する
- 生成後に誤字、漢字、文字化け、文字切れ、改行、人体、重なり、見切れ、余白、情報量、色、正式名称を再検品し、不合格なら修正してから完成とする

各プロンプトを1件だけコピーした場合も、この共通品質基準、制作工程、再検品条件が含まれます。

Instagramカルーセル9枚は、各イラスト内に大見出しと2〜4行の短い説明文を直接配置します。文字が人物の顔や重要部分に重ならない構図、高コントラスト、スマートフォンで読める文字サイズ、誤字・文字化け時の修正指示も含みます。

文字やテロップでメインイラストを隠さないよう、画像を「テキスト専用エリア」と「イラスト表示エリア」に完全分離します。互いの領域へ1ピクセルも侵入させず、イラスト側には文字・帯・吹き出しを置きません。カルーセルは上部見出し18％・中央イラスト57％・下部説明カード25％を基本とし、中央の主役を完全に見せます。縦型動画でも映像エリアとテロップ帯を全フレームで固定し、SNSの操作ボタンと重ならない安全余白を確保します。

文字は太めの日本語ゴシック体を基本とし、媒体サイズごとに最低フォントサイズを指定します。カルーセルは大見出し64〜80px・説明文36〜44px以上、縦型動画は表紙96〜120px・通常テロップ72〜88px以上、YouTube横型動画は表紙88〜112px・通常テロップ64〜80px以上を基準にします。文字が収まらない場合も小さくせず、文章を短く要約するよう指示します。

日本語の改行は、句読点や意味のまとまりを基準にします。助詞・助動詞・句読点を行頭へ置かず、単語、固有名詞、商品名、数字と単位の途中で分割しません。各行を分割禁止のテキストとして配置して自動折り返しを無効にし、改行後は行の長さ・中央揃え・行間・余白・視覚的重心を再調整します。

GeminiがInstagramカルーセルを9枚以外で返した場合も、アプリ側で不足分を補い、余分な分を整理して必ず9枚にします。ブログ記事の画像プロンプトは、完成本文からH2・H3と直後の要点を抽出し、セクションごとに自動作成します。

各制作プロンプトには、用途を判別できる推奨保存ファイル名も表示します。例：`Instagram_カルーセル_01.png`、`Facebook_アイキャッチ.png`、`YouTube_動画.mp4`、`ブログ_H2_01_見出し名.png`。保存名は画面上の管理情報として表示し、制作プロンプト本文には混ぜません。そのため、SNS名やファイル名が画像・動画の中へ描かれることを防げます。

動画プロンプトでは、Instagram・YouTube・TikTokなどのSNS名やロゴを映像内へ表示しないよう指定します。動画は各媒体とも40〜45秒を基準とし、人の声や音声ナレーションは一切使用しません。これまでのナレーション文は、1シーン45文字以内の日本語テロップとして、左から右へ1文字ずつ現れるタイピング演出で表示します。1文字0.04〜0.07秒、入力完了後は1.5〜2秒保持し、テロップ間の空白は最大0.2秒、場面転換は0.2〜0.4秒とします。

動画は0.0秒の最初のフレームから完成した表紙を表示し、黒画面や待ち時間を入れません。表紙は3.5〜4秒表示し、キャッチコピーとイラストを落ち着いて確認できる時間を確保します。BGMは軽快なピアノ、ウクレレ、柔らかなギター、控えめな手拍子やパーカッションを使った、明るくポップで前向きな曲調にします。最後の商品案内は3〜4秒とし、商品が向く人へ押し売りにならない言葉で勧めます。リール・TikTokはプロフィール、YouTubeは概要欄のリンクへ案内します。

完成前には、プロのイラストレーター兼アートディレクターと映像ディレクターが、誤字、文字化け、自然な改行、文字バランス、余白、人物、手指、構図、配色、テロップのタイピング順序、保持時間、イラストとの重なり、音声混入、BGMの明るさと音切れを全フレームで確認します。続いてプロのマーケティングコンサルタントが、想定読者との一致、訴求力、視聴維持、媒体適合、【PR】表記、事実性、購入導線、押し売り感の有無を確認します。不合格項目があれば内部で修正・再検品し、合格した完成版だけを出力します。

GeminiがLINE投稿などをJSONオブジェクトではなく文字列で返した場合も、アプリ側で正しい形式へ自動変換します。過去の生成結果が画面に残っている場合も、SNSタブやダウンロード処理でエラーにならないよう安全に表示します。

## 無料で使う方法

記事・SNS文章・制作プロンプトには、利用可能な場合にGemini APIの無料枠を使います。画像・動画そのものは生成しないため、アプリ側で画像・動画生成APIの費用は発生しません。無料枠やGoogle検索連携の利用条件はGoogle側で変更される場合があるため、Google AI Studioの利用状況も確認してください。

1. [Google AI Studio](https://aistudio.google.com/apikey)を開く
2. Googleアカウントでログイン
3. Gemini APIキーを作成してコピー
4. アプリ左側の「Gemini APIキー」に貼り付け

無料枠には回数・速度の上限があります。商品ページURLは最初に直接取得し、ページ側に拒否された場合だけURL Contextへ切り替えます。URL Contextも利用できず、商品名が入力されている場合は、最後に商品名検索へ自動で切り替えます。

## Streamlit Community Cloudへ公開する方法

1. このフォルダ内のファイルをGitHubリポジトリへアップロード
2. Streamlit Community Cloudでリポジトリと `app.py` を選択
3. Advanced settingsまたはSettings → Secretsへ次を登録

```toml
GEMINI_API_KEY = "ここにGemini APIキー"
GEMINI_MODEL = "gemini-3.5-flash-lite"
```

4. SaveしてDeployまたはReboot

APIキーをGitHubへ直接書かないでください。

## Windowsで起動する方法

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## 使い方

1. 販売目的を選択
2. 商品名または商品の公式ページURLを入力
3. 「アフィリエイト」または「両方」の場合は、ASPなどで発行されたアフィリエイトURLを入力
4. 「院内・店舗販売」の場合、購入ページがなければ案内先URLは空欄で生成可能。店舗ページや問い合わせページがある場合だけ入力
5. 必要に応じてメーカー名、店舗・院・サービスの正式名称を入力
6. 「記事を生成する」を押す
7. 商品調査・記事・LP・店舗販促・SNS・制作プロンプトを確認し、必要な箇所を画面で編集
8. 個別ファイルまたは一括ZIPをダウンロード

### 販売目的の違い

- `アフィリエイト`：オンライン記事やSNSから、専用アフィリエイトURL経由の購入へ案内します。
- `院内・店舗販売`：店舗で直接販売します。URLがなければ、記事やSNSのCTAは「院内でスタッフへお声がけください」「ご来店時にご相談ください」になります。
- `両方`：院内・店舗でも販売し、来店できない方にはアフィリエイトURLからオンライン購入を案内します。購入・詳細確認欄にはアフィリエイトURLを入力します。

## 結果画面とダウンロード

生成後の画面は、次の5つのタブに分かれます。

1. `商品調査`：取得資料、商品要約、SEOキーワード
2. `記事・構成`：想定読者の悩み、SEO構成案、完成記事
3. `LP・店舗販促`：販売ページ、GBP投稿、店内POP、公開前チェック
4. `SNS・制作プロンプト`：各SNS投稿文、動画台本、画像・動画制作用プロンプト
5. `ダウンロード`：個別ファイルと一括ZIP

ダウンロードファイル名には、日本時間の生成日時（`YYYYMMDD_HHMM`）が自動で付きます。例：`affiliate_article_20261016_1115.md`。

「すべてのファイルを一括ダウンロード」では、次の7ファイルを1つのZIPにまとめます。

- 商品調査・商品要約・SEOキーワード
- 記事一式（想定読者の悩み・記事構成・完成本文）のMarkdown
- WordPress用HTML
- 販売ページ（LP）原稿
- GBP・店内POP・公開前チェック
- SNS投稿文
- 画像・動画制作用プロンプト

ダウンロード操作を専用タブへまとめているため、記事やSNSの確認画面と切り替えながら利用できます。生成結果はセッション内に保持され、ダウンロード時の再表示でも確認を続けられます。

## 注意事項

- ログイン必須ページ、JavaScriptだけで表示するページ、取得を拒否するページは読み込めない場合があります。
- 商品名だけのWeb調査が契約・モデル・利用上限により使えない場合は、商品の公式ページURLを入力してください。
- 公開前に商品情報、価格、在庫、キャンペーン、法令、各SNS・ASPの規約を確認してください。
- 架空の口コミや体験談は生成しない設計です。実体験は生成後にご自身の言葉で追加してください。
- 健康・美容商品は薬機法、景品表示法、健康増進法などに配慮してください。
- 画像・動画生成サービスによってプロンプトの解釈や使用条件が異なります。
